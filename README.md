# Student Attendance Monitoring System

A simple, command-line Python application for recording, viewing, and searching daily student attendance. All attendance logs are automatically stored in a local CSV file (`attendance_records.csv`) for easy tracking and record-keeping.

## Features
* **Mark Attendance:** Record student attendance as **Present**, **Absent**, or **Late** with automatic date stamping.
* **View Records:** Display a formatted table of all saved student attendance logs.
* **Search Student History:** Quickly look up attendance records using a Student ID or Name.
* **Automatic Storage:** Automatically creates and updates a CSV spreadsheet (`attendance_records.csv`) so data is saved permanently.

## How to Run
1. Make sure you have **Python 3** installed on your computer.
2. Download or clone this repository:
   ```bash
   git clone https://github.com
   ```
3. Navigate to the project folder and run the script:
   ```bash
   python attendance_system.py
   ```
